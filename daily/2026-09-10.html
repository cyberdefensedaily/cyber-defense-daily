Record Microsoft patches, Adobe zero-day, Chrome exploit mark heavy week

974 CVEs from Microsoft, exploited e-commerce flaw, and Chrome's seventh 2026 zero-day

Microsoft ships record 974 CVEs in September Patch Tuesday

Microsoft patched 974 vulnerabilities in its September update, including two zero-days actively exploited in the wild. The release broke prior records and spanned Windows, Office, SQL, and Azure products. CVE-2026-81963 affects the Windows Update Stack and CVE-2026-85880 targets the Advanced Local Procedure Call. [1]

Adobe patches StyleSmuggler zero-day exploited since September 4

CVE-2026-75650, a CVSS 10.0 unauthenticated remote code execution flaw in Adobe Commerce and Magento, was exploited for three days before Adobe released a hotfix on September 7. Attackers deployed Rust-based Linux backdoors and PHP web shells on vulnerable e-commerce servers. Adobe confirmed active exploitation and urged credential rotation in addition to patching. [2]

Chrome V8 zero-day marks seventh exploit of 2026

Google patched CVE-2026-87491, an out-of-bounds write vulnerability in Chrome's V8 engine, on September 8 after confirming active exploitation. The flaw allows arbitrary code execution inside the browser sandbox via a crafted HTML page. Four of 2026's seven Chrome zero-days have targeted V8 directly, signaling sustained adversary research into the JavaScript engine. [3]

F5 BIG-IP APM malware injects fileless PHP web shell

Attackers exploiting CVE-2025-53521 in F5 BIG-IP APM deployed PoisonedRefresh, a Linux rootkit that injects a PHP web shell directly into Apache process memory without altering files on disk. The malware modifies system binaries and embeds itself in upgrade images to survive device updates. More than 14,000 BIG-IP instances remain exposed globally months after patches became available. [4]
