Critical infrastructure flaws and Pentagon cyber strategy in focus

Cisco and PostgreSQL vulnerabilities disclosed as DoD strategy release nears

Cisco patches critical Nexus 9000 remote code execution flaw

Cisco disclosed CVE-2026-20212, a critical vulnerability with a CVSS score of 9.8 affecting select Nexus 9000 switches with Silicon One ASICs. The flaw allows unauthenticated remote attackers to execute code with root privileges through exposed TCP ports 43210 and 43211. Cisco reported no known exploitation as of the September 2 disclosure and has issued patches alongside temporary mitigation options including access control lists. [1]

PostgreSQL fixes 12-year-old vulnerability enabling server takeover

PostgreSQL patched CVE-2026-6471, a CVSS 7.2 vulnerability present since 2014 that allows attackers with replication privileges to execute arbitrary code and escalate to superuser access. The flaw, dubbed PostGREShell, stems from missing authorization in the logical decoding feature. Patches are available in PostgreSQL versions 18.6, 17.11, 16.15, 15.19, and 14.24, and organizations are advised to audit replication accounts immediately. [2]

Pentagon cyber strategy expected next week

The Defense Department is expected to release its new cyber strategy early next week, according to three sources familiar with the plan. The strategy, the first overarching cyber framework since 2023, will emphasize integrating cyber capabilities across all domains of warfare, offensive operations, and AI adoption. The action plan reportedly contains approximately nine strategic initiatives and 34 lines of effort, though the exact release date remains subject to change. [3]
