Zero-days, supply chains, and court chaos

China-linked hackers, credential theft, and a federal court outage mark the week

China-linked group exploited BeyondTrust zero-day since August

Armory Castle, a Chinese APT also tracked as UNC5221, exploited CVE-2026-102764 in BeyondTrust Remote Support appliances starting August 29, seven weeks before disclosure. The critical flaw allowed attackers to gain root access, deploy backdoors, steal credentials, and delete logs. BeyondTrust patched SaaS customers October 9; self-hosted customers running versions 24.3.1 through 26.2.3 must manually apply fixes. [1]

Attackers used stolen ConnectWise credential to access 173 Microsoft 365 tenants

Threat actors compromised a ConnectWise Cloud Backup credential and used it to sign into 173 Microsoft 365 customer tenants between October 14-15. The backup application holds broad permissions across Exchange, OneDrive, SharePoint, and Teams. ConnectWise shut down application access while investigating; no evidence yet that backup data itself was compromised. [2]

Cyberattack on BAE Systems disrupts federal bankruptcy courts nationwide

A security incident targeting BAE Systems took down the Bankruptcy Noticing Center, halting production and distribution of notices for all U.S. federal bankruptcy courts. At least 14 states reported delays or postponed proceedings as of October 16. BAE operates the BNC on behalf of the federal judiciary; officials have not confirmed whether case data was stolen. [3]

Microsoft patches 1,417 vulnerabilities, one already exploited

Microsoft's October 2026 Patch Tuesday addressed a record 1,417 CVEs, including 76 rated critical. CVE-2026-96951, a Windows Shell feature bypass, is under active exploitation and allows attackers to bypass Mark of the Web protections. CVE-2026-108398, a publicly disclosed .NET Framework flaw, permits bypassing Windows Defender Application Control. Ten critical remote code execution flaws affect Windows DHCP Server. [4]
