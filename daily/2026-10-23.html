Critical PHP Flaws Take Sites Offline, HPE Patches Maximum-Severity ArubaOS Bugs

AI-discovered PHP vulnerabilities force global site shutdowns as enterprise networks face authentication bypass risks

AI-discovered PHP vulnerabilities force widespread website shutdowns

Two critical vulnerabilities in PHP, dubbed PHP2Shell and tracked as CVE-2026-109618 and CVE-2026-109619, allow unauthenticated remote code execution on servers running roughly 70 percent of websites globally. Websites around the world went offline October 23 as operators scrambled to patch, including 32 UK government services. The U.S. NSA advised organizations to immediately update or take systems offline. CISA urged immediate patching for web-facing management servers and OT gateways. [1]

HPE patches eight maximum-severity flaws in ArubaOS wireless systems

Hewlett Packard Enterprise released fixes for 72 vulnerabilities in ArubaOS on October 22, including eight with maximum CVSS 10.0 scores allowing authentication bypass and remote code execution. The flaws affect AOS-8 and AOS-10 deployments across Mobility Conductors, Controllers, Gateways, and access points. Attackers can exploit the vulnerabilities remotely without privileges through low-complexity attacks requiring no user interaction. HPE reports no evidence of active exploitation as of the advisory release. [2]

Oracle issues emergency Java update for compromised eMudhra certificates

Oracle published an out-of-band security alert October 21 for CVE-2026-91403, a critical CVSS 9.1 flaw in Java SE and GraalVM that allows unauthenticated remote attacks. The vulnerability involves eight compromised eMudhra intermediate certificate authority certificates with weak private keys that Java continued to trust. Successful exploitation could expose sensitive data or allow attackers to modify application data during what appears to be secure connections. eMudhra revoked all eight intermediates on October 19. [3]

Attackers actively exploit Citrix NetScaler RCE flaw with web shells and malware

Citrix NetScaler ADC and Gateway appliances are under active attack via CVE-2026-88771, a critical unauthenticated remote code execution vulnerability disclosed September 27. Zscaler ThreatLabz observed attackers poisoning logs to trigger command execution, planting web shells, and attempting to deploy a FreeBSD x64 implant. CISA added the vulnerability to its Known Exploited Vulnerabilities catalog. Citrix confirmed exploitation against unmitigated deployments and assigned a CVSS 4.0 score of 9.5. [4]

CISA warns of nine critical Kiloview encoder vulnerabilities enabling full device compromise

CISA issued advisory ICSA-26-295-01 on October 22 identifying nine vulnerabilities in Kiloview E3 NDI Encoder firmware earlier than version 1.30. Successful exploitation could fully compromise the device through OS command injection, missing authentication, session expiration flaws, path traversal, null-pointer dereference, and hard-coded credentials. CISA reports no known public exploitation at publication but warns this is not evidence the device is safe. [5]
