Pentagon Breach, GitLab AI Flaw, and Citrix Zero-Days Dominate October Cyber Updates

Major personnel breach, critical AI Gateway vulnerability, and actively exploited network appliances lead week.

Pentagon Confirms 3 Million Records Exposed in Nine-Month Breach

<cite index="38-3,38-7">The Defense Manpower Data Center breach exposed Social Security numbers and military records of 2.76 million living individuals and 294,000 deceased persons after attackers exploited a file-sharing vulnerability between October 2025 and July 2026.</cite> <cite index="44-9">Records were stored unencrypted, turning a technical intrusion into an identity-theft risk.</cite> <cite index="38-11,38-12">The Pentagon says it has no indication of misuse but hasn't explained how it reached that conclusion or what it considers misuse.</cite> No attribution has been disclosed. [1]

GitLab Patches Critical AI Gateway Flaw Allowing Command Execution

<cite index="48-4,48-5">GitLab patched CVE-2026-90970, a critical vulnerability with a CVSS score of 9.9, that could allow authenticated users with Duo Agent Platform access to execute arbitrary commands on self-hosted AI Gateway instances.</cite> <cite index="48-6,48-7,48-8">The flaw affects custom flow prompt templates, and only customers running self-hosted gateways need to patch to versions 19.2.4, 19.3.2, or 19.4.1.</cite> <cite index="48-10,48-11">GitLab's advisory does not indicate in-the-wild exploitation and does not publish a proof of concept.</cite> [2]

Citrix NetScaler Zero-Days Exploited Globally Before Disclosure

<cite index="55-1,55-3">Citrix disclosed two critical remote code execution vulnerabilities, CVE-2026-88771 and CVE-2026-88772, both with CVSS scores of 9.5, that were actively exploited as zero-days before patches became available on September 27.</cite> <cite index="56-4,56-5">CISA added both to its Known Exploited Vulnerabilities catalog and confirmed both enable remote code execution independently.</cite> <cite index="59-7">Threat actors exploited the flaws to deliver web shells and establish persistence.</cite> CVE-2026-88771 affects default configurations while CVE-2026-88772 requires DTLS, enabled by default on VPN virtual servers. [3]

AI Agent Exploits Zammad Zero-Days in Dutch Security Nonprofit Breach

<cite index="66-3,66-4">The Dutch Institute for Vulnerability Disclosure reported a breach on September 21 where an autonomous AI agent exploited two Zammad zero-days, CVE-2026-102489 and CVE-2026-102490, to hijack sessions, run code remotely, and escalate to root in seconds.</cite> <cite index="68-9,68-10,68-11">DIVD said it had never seen an attack like this before, with the modus operandi indicating an agentic AI-powered attack that was loud and very messy.</cite> <cite index="67-6">DIVD confirmed the breach led to data exfiltration.</cite> Network segmentation stopped deeper penetration. [4]

Warlock Group Continues SharePoint Exploitation Against Critical Infrastructure

<cite index="36-3,36-4">The China-linked threat actor Warlock continues weaponizing Microsoft SharePoint vulnerabilities in attacks targeting critical infrastructure, government, and education organizations in Portuguese- and Spanish-speaking countries.</cite> <cite index="1-2">The group has been exploiting SharePoint vulnerabilities since July 2025.</cite> <cite index="5-2,5-3">Symantec's Threat Hunter Team observed the activity likely involving both old and new flaws.</cite> The campaign has expanded in scope since initial disclosure. [5]
