Three zero-days exploited, Microsoft patches record CVE count, China tightens AI export rules

Active exploitation of Ivanti and BeyondTrust flaws, critical Linux VM escape, and 1,413 Microsoft patches lead today's brief.

China-linked group exploited BeyondTrust zero-day for two months before disclosure

ARMORY CASTLE exploited CVE-2026-102764 in BeyondTrust Remote Support as a zero-day starting in late August, gaining root access and harvesting credentials from compromised appliances. BeyondTrust patched the critical flaw on October 8, but Google Threat Intelligence warns organizations should prepare for broader exploitation now that details are public. The vulnerability allows unauthenticated remote attackers to perform file operations and achieve full host control. [1]

Ivanti Connect Secure zero-day exploited since October 1, CISA sets remediation deadline

Threat actor UTA0576 chained three zero-day vulnerabilities in fully patched Ivanti Connect Secure appliances to achieve unauthenticated root access and exfiltrate Active Directory credentials, LAPS passwords, and BitLocker keys. Ivanti disclosed CVE-2026-104935 on October 13 after Volexity discovered the exploitation chain, and CISA added the flaw to its Known Exploited Vulnerabilities catalog with a remediation deadline of October 16. One privilege escalation flaw in the chain remains unpatched. [2]

Critical Linux kernel flaw lets guest VMs read host memory, demonstrated against live cloud

Security researcher Paulos Yibelo disclosed CVE-2026-99999, dubbed PwnEscape, a critical Linux networking vulnerability that allows code inside guest VMs to read host memory and potentially achieve full VM escape. The researcher demonstrated host memory disclosure against Vercel's production sandboxes during its security challenge, and Vercel confirmed the finding. The flaw affects Linux kernel networking code rather than specific hypervisors, requiring host-level patching by cloud providers. [3]

Microsoft patches record 1,413 vulnerabilities including actively exploited zero-day

Microsoft released patches for 1,413 vulnerabilities in its October 2026 Patch Tuesday, the highest monthly total on record and exceeding all CVEs patched in 2025. CVE-2026-96951, a Windows Shell security feature bypass already under active exploitation, allows attackers to bypass Mark of the Web protections. CISA ordered federal agencies to remediate the flaw by October 16. [4]

China implements interim AI export registration requirement while finalizing controls

China's commerce and science ministries activated an interim registration requirement on October 16 for exporters of 40 technologies across AI, biomedicine, and photovoltaics while a proposed revision to export control catalogues undergoes public consultation through November 15. The registration requirement applies immediately to covered technology transfers, including those already underway, though the broader catalogue revisions have not yet been finalized. [5]
